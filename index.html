Semana 1: Introducción a Arduino

Arduino es una plataforma de hardware y software libre, flexible y fácil de usar para creadores y desarrolladores. Permite crear microordenadores de una sola placa con especificaciones de acceso público para que cualquiera pueda replicarlos.

Semana 2: Estilos con CSS

Hoy empezamos a usar Flexbox y a darle colores neón a nuestros títulos. ¡Se ve genial!

Semana 3: Control de Luces LED con Arduino

En esta sesión pusimos en práctica los conceptos básicos de programación en Arduino para controlar el encendido, apagado y secuencias de luces LED en la placa de pruebas (breadboard).

Semana 4y5: semana 4 Entradas Analogicas y Sensores

[En esta sesión aprendimos sobre las señales análogas, las cuales pueden tomar múltiples valores continuos dentro de un rango determinado. Vimos cómo el Arduino procesa estas señales usando sensores para interactuar con el entorno físico.]

Semana 6: Sensor Ultrasonico

[En esta sesión simulamos en Tinkercad un sensor ultrasónico (HC-SR04), el cual utiliza ondas de sonido de alta frecuencia para medir distancias. Aprendimos a calcular el tiempo que tarda la onda en ir y regresar para convertirlo en centímetros mediante código en Arduino.]

Semana 7: Sensor PIR

En la última sesión trabajamos con el sensor PIR (Infrarrojo Pasivo) en Tinkercad para la detección de movimiento. Analizamos cómo el sensor captura la radiación infrarroja de objetos en movimiento y cómo enviar una señal digital al Arduino para activar respuestas automáticas.
